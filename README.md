# 🛒 EconoMarket — Landing Page Oficial

Landing Page de alta conversão construída em **React 19, Vite 6 e Tailwind CSS**, apresentando o aplicativo **EconoMarket** com identidade visual autoral Fresh Market.

---

## ✨ Seções & Destaques

1. **Navbar:** Navegação fluida com âncoras suaves e status 100% Offline & Seguro.
2. **Hero:** Proposta de valor clara com headline de alto impacto, badges de confiança e mockup interativo do smartphone com o app real.
3. **Como Funciona:** Jornada em 4 passos (Planejar, No Carrinho, Escanear Cupom e Celebrar Economia).
4. **Simulador Interativo ao Vivo:** Carrinho funcional onde os visitantes podem clicar nos produtos, alterar quantidades, ver a variação percentual mês a mês e acompanhar o impacto em R$ no bolso.
5. **Scanner Híbrido (Showcase):** Explicação da **Opção A (QR Code NFC-e SEFAZ)** e **Opção B (Foto com Gemini Flash Vision)** + garantia da Tela de Conferência.
6. **Grade de Benefícios da Dona de Casa:** Thumb Zone (uma mão só), clonagem em 1 clique, detecção de inflação pessoal e privacidade WatermelonDB.
7. **Tabela Comparativa:** EconoMarket vs Caderno de Papel vs Apps Genéricos de Lista.
8. **Depoimentos Reais:** Prova social de quem cuida da economia da casa.
9. **FAQ Completo:** Respostas sobre funcionamento offline, segurança e leitura de notas fiscais.
10. **Footer de Conversão:** Links, garantia de privacidade e botões de download.

---

## 🚀 Como Executar

Na pasta `/Volumes/crucial-x9/ideias/econo-market-lp`:

```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento Vite
npm run dev

# 3. Compilar para produção
npm run build
```
